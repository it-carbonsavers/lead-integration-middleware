# Operations

## Lead sources

- **Add a source:** Lead Sources → Add source, then issue an API key (shown once; send it securely).
- **SFTP:** on the source's Consent recordings tab, choose SSH key or password login, save, then Test connection.
- **Suspend:** a suspended source's API requests and SFTP login are refused.

## Failed deliveries

Open the lead, read the delivery attempts, fix the cause, then **Retry delivery**.

## Recordings

- **Not matched:** link the file to its lead from Consent Recordings → Recording files.
- **Rejected:** the reason is shown; ask the provider to resend a correct file.
- **Overdue:** the recording did not arrive within 48 hours; follow up with the provider.

## Users

Add, disable or reset users under Settings → Users & access. Every action is recorded in Settings → Audit log.

## HubSpot

HubSpot delivery stays switched off until approved. Test with a HubSpot sandbox first.
